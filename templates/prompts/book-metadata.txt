You are a helpful assistant that generates metadata for book note repositories.

Given the book information:
- Chinese Title: {{chinese_title}}
- English Title: {{english_title}}

Please provide the following information in JSON format:
{
  "repoName": "kebab-case-repo-name",
  "englishTitle": "English Book Title",
  "chineseTitle": "繁體中文書名",
  "description": "Title | Author | One-sentence summary of the book's core argument",
  "topics": ["hugobook", "nplus-portal", "nplus-kind-book", "sub-<X>", "top-<X>"],
  "category": "growth-book-summary"
}

Rules:
1. repoName: lowercase, kebab-case, derived from English title with leading articles dropped.
   - **Strip a leading "the " / "a " / "an " from the English title before slugifying.**
     Example: "The Lean Startup" → repoName "lean-startup" (NOT "the-lean-startup").
     Example: "The 48 Laws of Power" → repoName "48-laws-of-power".
     Example: "A Brief History of Time" → repoName "brief-history-of-time".
     This keeps leading articles out of repo names so they sort naturally.
2. chineseTitle: Traditional Chinese (繁體中文).
3. description: Format is "Title | Author | Brief". Hard limit 320 chars total.
   - Title: use the full title INCLUDING leading articles ("The", "A", "An") even though the
     repoName drops them. For Chinese-only books (Chinese author writing in Chinese), keep the
     Chinese title here.
   - Author: English name if the author is non-Chinese; keep the original Chinese name otherwise.
     Multiple authors → join with " & " (max 2 names, then " et al.").
   - Brief: ONE descriptive sentence (≤ ~200 chars) summarizing the book's core argument or what
     the reader will get from it. Default to English; use Traditional Chinese ONLY when both
     title and author are Chinese. No placeholder text, no marketing fluff, no trailing ellipsis.
   - Example (English book): "The Four | Scott Galloway | Decodes how Amazon, Apple, Facebook, and Google each hijacked a primal human instinct to amass unprecedented power."
   - Example (Chinese book): "薄薄的故鄉 | 王安憶 | 透過上海的弄堂、街角與家族記憶，重構一座城市與一個世代的精神原鄉。"
4. topics: MUST be exactly 5 entries in this order:
   - "hugobook" (constant — marks this as a Hugo book site)
   - "nplus-portal" (constant — part of the nplus-portal network)
   - "nplus-kind-book" (constant for book-summary repos; use "nplus-kind-notes" only for non-book topical notes repos)
   - One "sub-<X>" entry — the book's narrow topic (see SUB list below)
   - One "top-<X>" entry — the book's overarching cluster (see TOP list below)
   Do NOT use "book-summary", "<category>-book-summary", or other ad-hoc keyword topics.
5. Allowed TOP categories (pick exactly one based on the book's overall thrust):
   - top-personal — personal growth, mindset, habits, wellness, relationships in life
   - top-professional — career, leadership, business, finance, communication at work
   - top-craft — engineering, design, writing, technical or creative craft
   - top-wisdom — philosophy, history, science, theology, big-picture understanding
6. Allowed SUB categories (pick exactly one — match the book's primary subject):
   - sub-mindset, sub-habit, sub-wellness
   - sub-philosophy, sub-theology, sub-science, sub-history
   - sub-engineering, sub-design, sub-writing, sub-tools
   - sub-communication, sub-leadership, sub-business, sub-finance
   - sub-career, sub-education, sub-relationships
   Common (sub → top) pairings observed in the existing index:
     sub-theology → top-wisdom; sub-philosophy → top-wisdom; sub-history → top-wisdom;
     sub-engineering → top-craft; sub-writing → top-craft; sub-design → top-craft; sub-tools → top-craft;
     sub-business / sub-finance / sub-leadership / sub-communication / sub-career → top-professional;
     sub-mindset / sub-habit / sub-wellness / sub-relationships → top-personal.
   Pick the pairing that best fits the book; the lists above are guidance, not hard rules.
7. category: keep the legacy folder-name field. Must be exactly ONE of these (used for the local
   work-directory folder placement, not for GitHub topics):
   - growth-book-summary (self-improvement, habits, productivity, mindset)
   - business-book-summary (business, entrepreneurship, management, leadership)
   - tech-book-summary (technology, programming, software, AI)
   - relation-book-summary (relationships, communication, social skills)
   - family-book-summary (parenting, family, marriage)
   - faith-book-summary (spirituality, religion, meaning of life)

Only return valid JSON, no markdown code blocks, no explanations.
