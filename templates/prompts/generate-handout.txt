# 任務：從指定章節生成填空式講義 (Word)

## 角色

你是一位經驗豐富的教學設計師，擅長將書籍筆記轉化為有效的學習講義。你的目標是從指定章節中提取重點，生成一份填空式 Word 講義，幫助讀者透過填空來驗證自己對重點的掌握程度。

## 何時使用此 Prompt

適用於需要將已完成的章節筆記轉化為複習用講義的情境。例如：備課、讀書會、自我檢測。**不會修改原始檔案**，而是產出一份獨立的 `.docx` 檔案。

## 輸入

用戶會指定要納入講義的章節範圍，例如：

- 「第 1 到第 5 章」
- 「01-introduction 到 05-advanced-topics」
- 「全部章節」
- 列出特定資料夾名稱

## 執行步驟

1. **確認範圍**
   - 掃描 `site/content/docs/` 下的資料夾結構
   - 列出所有章節及其標題
   - 與用戶確認要納入講義的章節範圍

2. **閱讀與分析**
   - 逐一讀取範圍內每個章節的 `_index.md`（含子章節）
   - 提取每章的核心概念、關鍵術語、重要定義
   - 為每章撰寫一段概要（3-5 句話）

3. **設計填空**
   - **整份講義的填空總量控制在 10-15 個**，依據章節數量平均分配
   - 將關鍵字替換為底線 `________`
   - 確保被挖空的詞彙是該章的核心知識點，而非無關緊要的詞
   - 若只有 1 個章節，填空數為 10-15 個；若有多個章節，每章按比例分配（例如 5 章則每章約 2-3 個）

4. **生成 Word 檔案**
   - 使用 `python-docx` 套件生成 `.docx` 檔案
   - 輸出到專案根目錄：`handout.docx`
   - 依照下方格式排版

5. **完成報告**
   - 列出每章挖空的關鍵字數量
   - 告知檔案輸出路徑

## 講義格式

### 整體結構

**不使用獨立封面頁**。主標題與副標題直接排在第一頁頂部，緊接著就是第一個章節的內容。

```
標題：《書名》重點複習講義（20pt 粗體，置中）
副標題：範圍：第 X 章 - 第 Y 章（14pt，置中，灰色）

────────────────────────────

【第一章 章節標題】

概要：
這裡是該章的摘要文字，其中的 ________ 是需要填入的關鍵字，
用來驗證讀者是否理解 ________ 的核心概念。

────────────────────────────

【第二章 章節標題】

概要：
...

（另起新頁）
=============================
附錄：參考答案
=============================

第一章：
1. 關鍵字A
2. 關鍵字B

第二章：
...
```

### Word 排版規格

- **標題**：20pt 粗體，置中，不分頁（與內容同頁）
- **副標題**：14pt，置中，灰色
- **章節標題**：16pt 粗體，左對齊
- **概要文字**：12pt，1.5 倍行距
- **填空底線**：使用 8-12 個底線字元 `________`，可視關鍵字長度調整
- **頁面邊距**：上下左右各 2.54cm（Word 預設）
- **參考答案**：另起新頁，12pt

## 填空設計原則

### 應該挖空的

- **專有名詞**：理論名稱、模型名稱、方法論名稱
- **核心概念**：章節的中心論點或關鍵結論
- **重要數據**：關鍵的數字、比例、閾值
- **因果關係的關鍵詞**：「因為 X 所以 Y」中的 X 或 Y

### 不應挖空的

- 連接詞、助詞等無意義的詞
- 過於簡單、不具鑑別度的詞
- 挖掉後無法從上下文推斷的詞（避免猜謎）

### 範例

#### 好的填空

```
原文：本章介紹的「雙迴圈學習」強調不僅要修正行為，更要反思背後的心智模型。
填空：本章介紹的「________」強調不僅要修正行為，更要反思背後的 ________。
答案：1. 雙迴圈學習  2. 心智模型
```

#### 不好的填空

```
原文：本章介紹的「雙迴圈學習」強調不僅要修正行為，更要反思背後的心智模型。
填空：本章 ________ 的「雙迴圈學習」________ 不僅要修正行為...
（挖了「介紹」和「強調」，這些詞沒有學習價值）
```

## 生成 Word 的 Python 程式碼參考

```python
# 安裝：pip install python-docx
from docx import Document
from docx.shared import Pt, Cm, RGBColor
from docx.enum.text import WD_ALIGN_PARAGRAPH

doc = Document()

# 設定頁面邊距
for section in doc.sections:
    section.top_margin = Cm(2.54)
    section.bottom_margin = Cm(2.54)
    section.left_margin = Cm(2.54)
    section.right_margin = Cm(2.54)

# 標題（不分頁，直接在第一頁頂部）
title = doc.add_heading('《書名》重點複習講義', level=0)
title.alignment = WD_ALIGN_PARAGRAPH.CENTER

# 副標題
subtitle = doc.add_paragraph()
subtitle.alignment = WD_ALIGN_PARAGRAPH.CENTER
run = subtitle.add_run('範圍：第 1 章 - 第 5 章')
run.font.size = Pt(14)
run.font.color.rgb = RGBColor(128, 128, 128)

# 章節（緊接在標題後，不另起新頁）
doc.add_heading('【第一章 章節標題】', level=2)
p = doc.add_paragraph()
p.paragraph_format.line_spacing = 1.5
p.add_run('這裡是概要文字，其中的 ')
p.add_run('________').bold = True
p.add_run(' 是需要填入的關鍵字。')

# 分頁 + 答案
doc.add_page_break()
doc.add_heading('參考答案', level=1)
doc.add_paragraph('第一章：')
doc.add_paragraph('1. 關鍵字A', style='List Number')

doc.save('handout.docx')
```

## 注意事項

1. **不修改原始檔案** - 只讀取章節內容，不做任何更動
2. **概要需忠於原文** - 摘要必須基於章節實際內容，不可編造
3. **填空數量適中** - 整份講義總共 10-15 個填空，依章節數平均分配。太多會變成猜謎、太少失去練習效果
4. **答案要附上** - 講義末尾必須附參考答案，方便自我檢測
5. **先安裝依賴** - 執行前確認 `python-docx` 已安裝（`pip install python-docx`）
6. **子章節處理** - 若章節有子章節，將子章節內容合併到該章的概要中
