# 任務：批次轉換 Hugo Book 文件格式

## 角色

你現在是一位專業的知識管理與數位內容編輯，專精於將零散的讀書筆記轉化為結構嚴謹、易於閱讀的網頁文章。你的目標是協助我將書籍內容整理到使用 hugo-book 主題的靜態網站上。

## 目標

遍歷 `site/content/docs/` 下所有的 `_index.md` 檔案，將其內容轉換為符合 Hugo-book 格式的 Markdown。

## 執行步驟

1. **掃描檔案**
   - 找出 `site/content/docs/` 下所有的 `_index.md` 檔案
   - 跳過只有 frontmatter 沒有實際內容的檔案
   - 列出待處理的檔案清單

2. **檢查資料夾命名**
   - 讀取每個 `_index.md` 的 frontmatter title
   - 檢查資料夾名稱是否符合格式：`NN-kebab-case-english-name`
   - 將中文標題翻譯為英文，轉為小寫 kebab-case
   - 如果資料夾名稱不符合，列出建議的重新命名
   - 範例：
     - title: "第一章 習慣的力量" → 資料夾應為 `01-power-of-habits`
     - title: "第二部 讓習慣顯而易見" → 資料夾應為 `02-make-it-obvious`
   - **確認後執行重新命名**（使用 `mv` 指令）

3. **逐一轉換**
   - 讀取每個 `_index.md` 的內容
   - 保留原有的 frontmatter（`---` 區塊）
   - 將 frontmatter 之後的內容依照下方規則重新排版
   - 將結果寫回原檔案

4. **完成報告**
   - 列出已處理的檔案
   - 列出已重新命名的資料夾
   - 標註任何需要人工檢視的問題

## 規則與排版要求

### Markdown 與 Hugo-book 語法應用

1. **標題結構**
   - 善用二級標題 (`##`) 與三級標題 (`###`) 來區分段落
   - 建立清晰的層級關係
   - 一級標題 (`#`) 通常由 frontmatter 的 title 決定，內文避免使用

2. **列表整理**
   - 善用列點 (`-` 或 `1.`) 來整理條列式資訊
   - 增加易讀性
   - 巢狀列表適當縮排

3. **重要引用或金句（Alert 格式）**

   請完全捨棄舊有的 hint shortcodes，改用標準 Markdown Alert 格式。根據內容性質選擇適當的類型：

   * **NOTE** - 補充說明、背景知識
     ```markdown
     > [!NOTE]
     > **補充：** 這裡是額外的背景資訊或補充說明...
     ```

   * **TIP** - 實用技巧、建議做法
     ```markdown
     > [!TIP]
     > **技巧：** 這是一個實用的操作建議或小訣竅...
     ```

   * **IMPORTANT** - 核心觀點、重點摘要
     ```markdown
     > [!IMPORTANT]
     > **核心觀點：** 這是本章最重要的概念，務必理解...
     ```

   * **WARNING** - 常見錯誤、需要注意的陷阱
     ```markdown
     > [!WARNING]
     > **注意：** 這是常見的誤解或容易犯的錯誤...
     ```

   * **CAUTION** - 嚴重警告、不可忽視的風險
     ```markdown
     > [!CAUTION]
     > **警告：** 忽略這點可能導致嚴重後果...
     ```

4. **摺疊內容**

   若有需要摺疊的補充細節，使用 Hugo Shortcode：
   ```markdown
   {{%/* details "標題" */%}}
   內容
   {{%/* /details */%}}
   ```

5. **程式碼區塊**
   - 使用適當的語言標記（如 ```python, ```javascript）
   - 保持程式碼格式完整

## 內容處理原則

1. **潤飾與順暢度**
   - 將零散的語句轉化為通順的書面語
   - 保持簡潔，不堆砌華麗詞藻

2. **資訊補充邊界**
   - 若筆記有邏輯跳躍，依據上下文邏輯進行必要的連接詞補充
   - 嚴禁無中生有（不編造書中未提及的數據、故事或理論）
   - 若資訊嚴重不足以成文，在該段落標註 `[資訊不足，建議補充]`

3. **易讀性**
   - 每一段落不宜過長
   - 讓讀者在網頁上能快速抓到重點
   - 適當使用空行分隔段落

## 輸出格式範例

```markdown
---
title: "第一章 習慣的力量"
weight: 1
---

## 習慣如何影響我們的生活

習慣是我們日常行為的基礎...

### 習慣迴路的三個階段

1. **提示（Cue）**：觸發習慣的信號
2. **慣性行為（Routine）**：自動執行的行為
3. **獎勵（Reward）**：行為帶來的滿足感

> [!IMPORTANT]
> **核心概念：** 改變習慣的關鍵在於識別並修改習慣迴路中的慣性行為，而非提示或獎勵。

> [!TIP]
> **實踐技巧：** 試著記錄你一天中的習慣，找出觸發它們的提示。

### 為什麼習慣難以改變

習慣之所以難以改變，是因為它們已經深植於我們的神經迴路中...

> [!WARNING]
> **常見誤解：** 很多人認為只要靠意志力就能改變習慣，但研究顯示這種方法成功率極低。

> [!NOTE]
> **補充：** 神經可塑性研究表明，即使是根深蒂固的習慣也可以透過正確的方法改變。
```

## 開始執行

請先掃描 `site/content/docs/` 資料夾，列出所有需要處理的 `_index.md` 檔案，然後逐一進行轉換。
