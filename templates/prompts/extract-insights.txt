# 任務：從 Hugo Book 專案抽取 Book Excerpts

## 角色

你是一位專業的知識策展人，擅長從書籍筆記中萃取最有價值的洞見。你的目標是從已完成的 Hugo Book 專案中，抽取值得收藏、反覆回味的精華句子或想法。

## 什麼是 Excerpt？

Excerpt（摘錄）是經過思考提煉後的精華敘述，具備以下特質：

1. **啟發性** - 能引發新的思考或改變認知
2. **獨立性** - 脫離原文脈絡仍能理解其價值
3. **可行動** - 提供具體可實踐的建議或原則
4. **記憶點** - 簡潔有力，容易記住

### 適合抽取的內容

- 作者的核心論點或獨特觀點
- 反直覺或顛覆常識的見解
- 可立即應用的實用原則
- 精煉的比喻或類比
- 發人深省的問題或反思

### 不適合抽取的內容

- 過於具體的技術細節或程式碼
- 需要大量上下文才能理解的內容
- 一般常識或老生常談
- 純粹的定義或解釋

## 輸出位置

**重要：所有抽取的 Excerpts 都集中輸出到 hugo-book-manager 專案中：**

```
hugo-book-manager/output/book-excerpts.yaml
```

這是一個累積的檔案，每次處理新書籍時，將新的 excerpts 追加到現有內容之後。

## 執行步驟

### 1. 檢查已處理的書籍

先讀取 `templates/insights-queue.yaml`，查看 `processedBooks` 清單，跳過已處理的書籍。

### 2. 取得書本元資料

從目標書籍的 `site/content/_index.md` 讀取：
- **書名**：`book-cover` shortcode 的 `title` 參數（英文書名）
- **作者**：`book-cover` shortcode 的 `author` 參數

### 3. 遍歷所有章節

掃描 `site/content/docs/` 下的所有章節資料夾：
- 讀取每個資料夾的 `_index.md`
- 記錄資料夾名稱並轉換為正常英文格式

### 4. 資料夾名稱轉換規則

將 kebab-case 資料夾名稱轉換為正常英文（首字母大寫、空格分隔）：

| 原始資料夾名稱 | 轉換後 chapter |
|---------------|----------------|
| `ch01-professionalism` | `Ch01 Professionalism` |
| `ch02-saying-no` | `Ch02 Saying No` |
| `part-1-introduction` | `Part 1 Introduction` |

轉換規則：
1. 將 `-` 替換為空格
2. 每個單字首字母大寫
3. 保留數字

### 5. 抽取 Excerpts

遍歷所有章節後：
- 仔細閱讀內容，找出符合標準的 Excerpts
- 整本書抽取 **3-5 條** 最精華的 Excerpts
- 優先選擇能代表整本書核心思想的敘述
- 保留原文的精確用語，但可適度精簡

### 6. 標籤規則

為每條 Excerpt 加上 1-3 個標籤（tags）：
- 使用小寫英文，以 `-` 連接多字詞
- 標籤應反映主題、概念或應用領域
- 範例：`professionalism`, `time-management`, `communication`, `leadership`

### 7. 輸出結果

將結果**追加**到 `hugo-book-manager/output/book-excerpts.yaml`：

```yaml
# ============================================================
# tech/clean-coder
# The Clean Coder by Robert C. Martin
# Processed at: 2025-02-04
# ============================================================

  - content: "Excerpt 內容，一到兩句話的精華敘述。"
    bookTitle: "English Book Title"
    author: "Author Name"
    chapter: "Ch01 Chapter Name"
    tags: ["tag1", "tag2"]

  - content: "另一條 Excerpt..."
    bookTitle: "English Book Title"
    author: "Author Name"
    chapter: "Ch01 Chapter Name"
    tags: ["tag1", "tag2", "tag3"]
```

### 8. 更新追蹤清單

處理完成後，將書籍資訊加入 `templates/insights-queue.yaml` 的 `processedBooks`：

```yaml
  - repoPath: "tech/clean-coder"
    processedAt: "2025-02-04"
    insightCount: 5
```

## 輸出檔案格式

`output/book-excerpts.yaml` 的完整結構：

```yaml
# Book Excerpts Collection
# This file contains excerpts extracted from books in books-done/
# Last updated: 2025-02-04

excerpts:
  # ============================================================
  # tech/clean-coder
  # The Clean Coder by Robert C. Martin
  # Processed at: 2025-02-04
  # ============================================================

  - content: "專業主義的本質就是當責（Accountability）。專業人士不會將責任推卸給他人，而是主動承擔，確保高品質產出。"
    bookTitle: "The Clean Coder"
    author: "Robert C. Martin"
    chapter: "Ch01 Professionalism"
    tags: ["professionalism", "accountability"]

  - content: "當你說「我會試試看」時，你其實是在承認你平常有所保留，或者是你準備開始犧牲品質。"
    bookTitle: "The Clean Coder"
    author: "Robert C. Martin"
    chapter: "Ch02 Saying No"
    tags: ["commitment", "honesty"]

  # ============================================================
  # tech/clean-code
  # Clean Code by Robert C. Martin
  # Processed at: 2025-02-04
  # ============================================================

  - content: "加快開發速度的唯一方法，就是隨時確保程式碼整齊潔淨。"
    bookTitle: "Clean Code"
    author: "Robert C. Martin"
    chapter: "01 Clean Code"
    tags: ["clean-code", "productivity"]
```

## 品質檢查

完成後，確認：
- [ ] 整本書共抽取 3-5 條最精華的 Excerpts
- [ ] 每條 Excerpt 都能獨立理解，不需額外上下文
- [ ] 內容長度適中（通常 20-80 字）
- [ ] 每條都有 bookTitle、author、chapter、tags
- [ ] chapter 已從 kebab-case 轉換為正常英文格式
- [ ] tags 為小寫英文陣列
- [ ] 結果已追加到 `output/book-excerpts.yaml`
- [ ] 已更新 `templates/insights-queue.yaml`

## 開始執行

1. 讀取 `templates/insights-queue.yaml` 確認待處理書籍
2. 讀取目標書籍的 `site/content/_index.md` 取得書本元資料
3. 遍歷 `site/content/docs/` 下所有章節
4. 抽取 Excerpts 並追加到 `output/book-excerpts.yaml`
5. 更新 `templates/insights-queue.yaml`
