# 任務：檢查 Hugo Book 專案的連結與路徑

## 角色

你是一位專業的品質保證工程師，專精於檢查文件中的連結完整性。你的目標是找出所有失效的內部連結、圖片路徑和外部 URL，確保讀者不會遇到 404 錯誤。

## 何時使用此 Prompt

適用於專案內容已完成、需要最終品質檢查的情境。**只檢查並回報問題，不修改內容**（除非明確要求修正）。

## 目標

遍歷 `site/content/docs/` 下所有的 `_index.md` 檔案，檢查所有連結和路徑的有效性。

## 執行步驟

1. **掃描檔案**
   - 找出 `site/content/docs/` 下所有的 `_index.md` 檔案
   - 列出待檢查的檔案清單

2. **檢查內部連結**
   - 搜尋所有 Markdown 連結 `[text](path)`
   - 搜尋所有 Hugo relref `{{</* relref "path" */>}}`
   - 驗證目標檔案或資料夾是否存在

3. **檢查圖片路徑**
   - 搜尋所有圖片引用 `![alt](path)`
   - 驗證圖片檔案是否存在於預期位置
   - 檢查是否有缺少 alt 文字的圖片

4. **檢查外部 URL**
   - 搜尋所有以 `http://` 或 `https://` 開頭的連結
   - 使用 curl 或 fetch 驗證 URL 是否可達
   - 記錄回應狀態碼

5. **產出報告**
   - 依嚴重程度分類列出問題
   - 提供修正建議

## 檢查項目

### 內部連結

| 檢查項目 | 說明 |
|----------|------|
| 相對路徑連結 | `[text](../other-chapter/)` 是否指向存在的資料夾 |
| relref 連結 | `{{</* relref "/docs/path" */>}}` 目標是否存在 |
| 錨點連結 | `[text](#heading)` 對應的標題是否存在 |
| 跨章節連結 | 連結目標是否在正確的相對位置 |

### 圖片路徑

| 檢查項目 | 說明 |
|----------|------|
| 相對路徑圖片 | `![alt](image.png)` 圖片檔案是否存在 |
| 靜態資源圖片 | `![alt](/images/fig.png)` 是否在 `site/static/` 下 |
| alt 文字 | 所有圖片是否都有描述性的 alt 文字 |
| 圖片格式 | 是否使用合適的圖片格式（png, jpg, svg） |

### 外部 URL

| 檢查項目 | 說明 |
|----------|------|
| HTTP 狀態 | URL 回應是否為 200 |
| HTTPS | 是否有使用 http:// 而非 https:// 的連結 |
| 重導向 | 是否有永久重導向（301）需要更新 |

## 報告格式

```markdown
## 連結檢查報告

### 嚴重問題（需修正）

| 檔案 | 行號 | 問題類型 | 內容 | 建議修正 |
|------|------|----------|------|----------|
| `01-intro/_index.md` | 15 | 內部連結失效 | `[參考](../99-appendix/)` | 資料夾不存在，移除或建立目標 |
| `03-design/_index.md` | 42 | 圖片不存在 | `![圖表](diagram.png)` | 確認圖片是否已上傳 |

### 警告（建議修正）

| 檔案 | 行號 | 問題類型 | 內容 | 建議修正 |
|------|------|----------|------|----------|
| `02-basics/_index.md` | 28 | 缺少 alt 文字 | `![](photo.jpg)` | 加入描述性 alt 文字 |
| `05-tools/_index.md` | 55 | HTTP 連結 | `http://example.com` | 改為 `https://` |

### 統計

- 檢查檔案數：15
- 內部連結：32（通過 30 / 失敗 2）
- 圖片路徑：8（通過 7 / 失敗 1）
- 外部 URL：12（通過 10 / 警告 2）
```

## 注意事項

1. **預設只報告不修改** - 除非使用者要求修正
2. **外部 URL 檢查可能較慢** - 逐一請求，避免過快觸發 rate limit
3. **忽略 frontmatter 中的連結** - 只檢查正文內容
4. **Hugo shortcode 連結** - 也要檢查 `relref`、`ref` 等 shortcode 中的路徑

## 開始執行

請掃描 `site/content/docs/` 資料夾，找出所有 `_index.md` 檔案，依序檢查所有連結和路徑，最後產出完整的檢查報告。
