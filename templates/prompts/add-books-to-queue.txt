# Add Books to Queue Prompt

## 任務說明
根據用戶提供的中文書名清單，查詢書籍資訊並建立 `books-queue.yaml` 配置。

## 輸入格式
用戶會提供一系列中文書名，每行一本書。

## 輸出格式
為每本書產生以下 YAML 配置：

```yaml
-   id: {english-book-name-in-kebab-case}
    status: pending
    chinese_title: "{中文書名}"
    english_title: "{英文書名}"
    author: "{作者名}"
    publication_date: "{Month DD, YYYY}"
    cover_url: "{封面圖片URL}"
    purchase_url: "{購買連結}"
    table_of_contents: |
        {目錄內容，保留原始格式}
```

## 欄位規範

### id
- 使用英文書名，轉換為 kebab-case
- 範例：`The Hard Thing About Hard Things` → `hard-thing-about-hard-things`
- 若無英文書名，使用中文書名的英文翻譯

### cover_url 優先順序
1. **優先使用 Amazon**：`https://m.media-amazon.com/images/I/{image-id}._SL1500_.jpg`
2. 無 Amazon 圖片時，使用博客來圖片

### table_of_contents
- 以博客來查詢到的目錄為主
- 保留原始章節結構和格式
- 使用 YAML 多行字串格式 `|`

### purchase_url 優先順序
1. Amazon（原文版）
2. 博客來（台灣中文版）
3. 其他購書平台

## 搜尋策略

1. **第一步：識別書籍**
   - 搜尋 `"{中文書名}" 博客來 作者`
   - 確認書籍的英文原名和作者

2. **第二步：取得封面圖片**
   - 搜尋 `"{英文書名}" amazon book cover`
   - 尋找 Amazon 產品頁的高解析度封面圖

3. **第三步：取得目錄**
   - 前往博客來書籍頁面
   - 複製完整目錄內容

## 範例輸入
```
麥肯錫教我的思考武器
什麼才是經營最難的事
```

## 注意事項
- 若書籍有多個版本，優先選擇最新版
- 日文書籍的英文書名使用日文原名（羅馬拼音或原文）
- 台灣作者的書籍，english_title 可使用中文書名的英文翻譯
- 確保 YAML 格式正確，字串使用雙引號包覆
