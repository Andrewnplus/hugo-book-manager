# AI Task Processing Guide for Claude Code

This guide explains how to process AI tasks generated by the Hugo Book Manager CLI.

## Overview

When the user runs CLI commands that require AI processing (like `init-book`, `rebuild-docs`, or `convert-docs`), the CLI generates task files in the `ai-tasks/input/` directory. You should read these files, process them according to the prompts, and write the results to `ai-tasks/output/`.

## Task Types

### 1. Metadata Generation (`metadata-request.json`)

**Purpose:** Generate book metadata from Chinese/English title

**Input file:** `ai-tasks/input/metadata-request.json`
```json
{
  "taskType": "generateMetadata",
  "promptFile": "templates/prompts/book-metadata.txt",
  "input": {
    "chineseTitle": "原子習慣",
    "englishTitle": "Atomic Habits"
  }
}
```

**Steps:**
1. Read the prompt template from `promptFile`
2. Replace `{{chinese_title}}` and `{{english_title}}` with values from `input`
3. Generate the metadata following the prompt instructions
4. Write valid JSON to `ai-tasks/output/metadata-response.json`

**Output format:**
```json
{
  "repoName": "atomic-habits",
  "englishTitle": "Atomic Habits",
  "chineseTitle": "原子習慣",
  "description": "Atomic Habits | James Clear | Build good habits and break bad ones",
  "topics": ["habits", "self-improvement", "productivity", "book-summary", "growth-book-summary"],
  "category": "growth-book-summary"
}
```

### 2. Docs Structure Generation (`structure-request.json`)

**Purpose:** Generate Hugo docs folder structure from table of contents

**Input file:** `ai-tasks/input/structure-request.json`
```json
{
  "taskType": "generateDocsStructure",
  "promptFile": "templates/prompts/book-structure.txt",
  "input": {
    "tableOfContents": "第一部 基礎\n第一章 習慣的複利效應\n..."
  }
}
```

**Steps:**
1. Read the prompt template from `promptFile`
2. Replace `{{table_of_contents}}` with the value from `input`
3. Generate the folder structure following the prompt instructions
4. Write valid JSON to `ai-tasks/output/structure-response.json`

**Output format:**
```json
{
  "sections": [
    {
      "folderName": "01-fundamentals",
      "title": "第一部 基礎",
      "weight": 1,
      "chapters": [
        {
          "folderName": "01-compound-effect",
          "title": "第一章 習慣的複利效應",
          "weight": 1
        }
      ]
    }
  ]
}
```

### 3. Document Conversion (`convert-request.json`)

**Purpose:** Convert cleaned Markdown to Hugo-book format

**Input file:** `ai-tasks/input/convert-request.json`
```json
{
  "taskType": "convertDocument",
  "promptFile": "templates/prompts/doc-convert.txt",
  "files": [
    {"inputFile": "/path/to/input/01-intro.md", "outputFile": "/path/to/output/01-intro.md"},
    {"inputFile": "/path/to/input/02-chapter.md", "outputFile": "/path/to/output/02-chapter.md"}
  ]
}
```

**Steps:**
1. Read the prompt template from `promptFile`
2. For each file in `files`:
   - Read the input file content
   - Replace `{{content}}` in the prompt with the file content
   - Generate the converted Markdown following the prompt instructions
   - Write the result directly to the specified `outputFile` path
3. No need to write to `ai-tasks/output/` - just write to the specified paths

## Quick Reference

When user says "請處理 AI 任務" (please process AI task):

1. Check `ai-tasks/input/` for pending task files
2. For each task file found:
   - Read the task JSON
   - Read the prompt template
   - Process according to task type
   - Write output to appropriate location
3. Confirm completion to the user

## Important Notes

- Always use Traditional Chinese (繁體中文) for Chinese text
- For `repoName` and `folderName`, use lowercase kebab-case
- JSON output must be valid (no markdown code blocks)
- For document conversion, write directly to the specified output paths
- The prompt templates contain detailed instructions - follow them carefully
