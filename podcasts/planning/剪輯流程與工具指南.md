# Podcast 剪輯流程與工具指南（Mac）

> Last Updated: 2026-05-29
> 適用：單人人聲 / 單鏡頭等規格化內容（恩普拉氏、院外門徒路）
> 環境：macOS（Homebrew）、剪輯主力 DaVinci Resolve（Fairlight）

---

## 1. 核心觀念：兩種「乾淨」要分階段

| 類型 | 屬於 | 何時做 | 工具 |
|------|------|--------|------|
| 切空白 / 切贅詞 | 剪輯 | **早做**（先讓素材變短） | auto-editor、文字稿驅動 |
| 去噪 / EQ / 壓縮 / 響度正規化 | 母帶處理 (mastering) | **最後做** | DaVinci Fairlight 或 ffmpeg |

> [!IMPORTANT]
> **響度正規化（-16 LUFS）一定放最後一步**，套在剪完的成品上，讀數才準。
> 不要「raw 一次全洗乾淨再開始剪」。

---

## 2. 推薦三段式工作流程

```
① 自動粗剪（切空白）        →  ② 人力精修（耳朵）        →  ③ 母帶處理
   auto-editor 腳本              DaVinci Fairlight            DaVinci 或 ffmpeg
   去掉死空氣、贅詞              內容取捨、順序、口誤        去噪/EQ/壓縮/響度
   保留 padding                 細部停頓、配樂擺放          -16 LUFS / -1 dBTP
```

- **① 可全自動（腳本）**：機械性、零主觀判斷。
- **② 必須人力**：靠耳朵與創意判斷，Claude 沒有耳朵，幫不上。
- **③ 可腳本化也可在 DaVinci 內完成**。

---

## 3. 「文字稿驅動剪輯」放在哪做

「刪一段文字 = 剪掉對應音/影」的互動介面**不在 Claude 這裡**，要靠專門工具：

| 工具 | 說明 | 中文 |
|------|------|------|
| **Descript**（最推薦） | Mac app，文字稿驅動剪輯的看家本領，最順 | 支援（準確度建議實測） |
| DaVinci Resolve | 較新版有內建 Audio Transcription / 文字編輯 | 需實測；轉錄多為 Studio 功能 |
| **DIY（Claude 可幫）** | whisper 轉帶時間碼逐字稿 + 產 cut-list，再用 ffmpeg 切 | whisper 中文佳 |

> Claude 能做的是「**生逐字稿 / 字幕 / cut-list**」這種前置；互動式「改文章即剪片」請用 Descript 或 DaVinci。

---

## 4. 鏈路參數（母帶處理標準）

```
1. High-pass 80Hz       去低頻隆隆聲
2. Denoise（輕量）       過度去噪會有金屬/機器人感
3. (選) EQ / De-ess
4. 輕壓縮 ~2:1~3:1       平整動態
5. 切空白               保留 150–300ms padding，別把呼吸全砍光
6. 響度正規化            -16 LUFS（單聲道可 -19）/ 真實峰值 ≤ -1 dBTP（用 limiter）
```

注意：**不要用 peak normalize 到 -0.1 dB**（聽感不一致、編碼後易爆音）；改用 **LUFS 響度正規化**。

---

## 5. DaVinci Resolve（Fairlight）對應表

| 鏈路步驟 | DaVinci 專有名詞 / 位置 |
|----------|------------------------|
| High-pass 80Hz | **EQ**（Inspector / Mixer 通道條），Band 1 設 HPF / Low Cut ~80Hz |
| Denoise | **Voice Isolation**（Studio，一鍵 AI，人聲強）；免費版 FairlightFX **Noise Reduction** |
| De-ess / EQ | FairlightFX **De-Esser**；六段參數 **EQ** |
| 壓縮 | Mixer 通道條 **Dynamics → Compressor**；或 Studio 的 **Dialogue Leveler**（一鍵平整對白） |
| 切空白 | DaVinci 無好用自動切靜默 → **用 auto-editor 先做**再進 DaVinci |
| 響度正規化 -16 LUFS | 片段右鍵 **Normalize Audio Levels** → 模式 **ITU-R BS.1770-4** → Target **-16 LUFS** |
| 真實峰值 -1 dBTP | **Master 匯流排掛 Limiter**，開 True Peak、天花板 -1 dB |
| 量表 | `Fairlight 選單 → Meters / Loudness`，目標設 -16 LUFS 看 Integrated |

- **免費版即可跑完整條鏈**；`Voice Isolation`、`Dialogue Leveler`、`Audio Transcription` 多為 **Studio**（一次性買斷 ~US$295）。
- **順序**：剪輯 → 每軌 EQ→去噪→De-ess→Compressor → 最後 Normalize Audio Levels → Master 掛 Limiter。

## 6. macOS 安裝（Homebrew）

```bash
# 基礎
brew install ffmpeg sox

# 自動切空白（需 Python；auto-editor 依賴 ffmpeg）
brew install python
pip3 install auto-editor

# 逐字稿（Apple Silicon 建議 whisper.cpp，吃 Metal 加速）
brew install whisper-cpp
# 或 OpenAI 版：pip3 install -U openai-whisper
```

## 7. 常用指令範本

### 7.1 自動切空白（粗剪）

```bash
# 切掉死空氣，左右保留 0.2 秒 padding，避免聽起來上氣不接下氣
auto-editor input.wav --margin 0.2sec --edit audio:threshold=4% -o tightened.wav
```

### 7.2 母帶處理（一鍵，最後一步）

```bash
# 高通 → 去噪 → 壓縮 → 響度正規化（-16 LUFS / -1 dBTP）
ffmpeg -i edited.wav -af \
"highpass=f=80,afftdn=nf=-25,acompressor=threshold=-18dB:ratio=3:attack=20:release=250,loudnorm=I=-16:TP=-1:LRA=11" \
master.wav
```

> [!TIP]
> 更準的響度：用 **two-pass loudnorm**（第一遍 `print_format=json` 量測，第二遍帶入 measured 值）。需要時請 Claude 產生 two-pass 腳本。

### 7.3 產逐字稿 / 字幕（whisper.cpp）

```bash
# 先轉 16k 單聲道 wav，再轉錄為 srt 字幕（中文）
ffmpeg -i master.wav -ar 16000 -ac 1 audio16k.wav
whisper-cli -m ggml-large-v3.bin -l zh -osrt audio16k.wav
```
