## 0. 為什麼這樣做（決策摘要）

- **沿用既有 feed**，不開新 RSS（保留現有訂閱數與評論）。

## 1. 命名規範

公開標題格式：

```
EPNNN｜【系列】書名／主題：一句鉤子 (n/N)
```

- 連載用 `(1/2)(2/2)`、`(1/4)…`；單集不加。
- 內部代號 / 檔名沿用既有慣例：`院路-EPNNN-題目(部數)`。
- **四個系列標籤**（取代舊的「佳作／名著／小品／研經」抽象類別）：

| 系列標籤 | 內容 | 形態 |
|---|---|---|
| 【診療室遇見摩西】 | 聖經人物靈修對談 | **保留對談**（唯一例外） |
| Reading Keller | 提摩太・凱勒著作導讀 | Andrew 主講（重錄） |
| 【逐卷讀經】 | 整卷聖經研讀 | Andrew 主講（重錄） |
| 【啃一本大書】 | 系統神學等大部頭經典 | Andrew 主講（重錄） |

> 系列名與下方「鉤子」皆為建議、可改；定稿前先把鉤子當佔位用。

### 1.1 系列命名準則（含後續新內容）

四個系列是固定的「品牌層」，書名／主題是第二層。新內容一律掛在這四個系列下，不再新增抽象類別。

**【逐卷讀經】整卷研讀**——大部頭書卷連載多集，每集標題帶段落鉤子：

```
EPNNN｜【逐卷讀經】書名 NN：段落主題（章節範圍）
```

- `NN` = 該書卷內兩位數流水序（01、02…），跨集連續；短卷（如約拿書）可省略。
- 括號放經文範圍，方便對照。

| 書卷 | 一句話定位（北極星） | 備註 |
|---|---|---|
| 約拿書 | 一卷關於神、而不是關於魚的書 | 短卷，1–2 集 |
| 羅馬書 | 神的福音：神向全人類所發的忿怒與恩典 | 連載中 |
| **路加福音**（將引入） | 一位醫生筆下、為失喪者而來的耶穌——寫給「門外人」的好消息 | 24 章，長連載；**與節目「院外」調性天作之合，可當招牌** |
| **創世記**（將引入） | 起初，神…—萬物、墮落，與恩典的起點 | 50 章，長連載 |

> [!IMPORTANT]
>
> 創世記後半（亞伯拉罕、以撒、利百加、雅各、約瑟）會與「診療室遇見摩西」人物重疊。刻意區隔調性：**逐卷讀經＝按章釋經、看救贖線**；**診療室＝單一人物、靈修對談**。開場簡介點明「這是逐章讀，不是人物靈修」即可。

其餘三個系列維持單層命名：
- **Reading Keller 書名：鉤子 (n/N)**——按書，凱勒著作導讀。
- **【啃一本大書】書名．章節：鉤子 (n/N)**——系統神學等大部頭經典。
- **【診療室遇見摩西】人物：鉤子**——人物靈修對談，唯一保留多人形態。

## 3. 每週執行 SOP

對每一集，依序：

1. **備好音檔**
   - 🎙️ 重錄集：錄 solo → auto-editor 粗剪 → DaVinci 精修。
   - ♻️ 診療室集：取原始音檔（不重錄內容）。
2. **母帶處理**（兩者都要，求全頻道一致）：`-16 LUFS / -1 dBTP`，跑 `剪輯流程與工具指南.md` 的鏈路。
3. **以全新單集上架**到 SoundOn：新標題、新內部代號、放在序列下一個 pubDate（**新 GUID，勿沿用舊集**）。
4. **刪除對應舊集**（見第 4 節對照），同週完成。
5. 1:1 對應發 FB／IG 各一則（沿用既有社群規則）。

> [!TIP]
>
> 公開節奏建議**週更**，24 集約半年。瓶頸在 13 集重錄；10 集診療室重上傳是低工，可預先批次做好排程，但**對外維持穩定週更**，每週都有一次推播。
