## 1. 頻道定位總覽

| 項目 | 院外門徒路 | 恩普拉氏 |
|------|-----------|---------|
| 角色 | 信仰主題節目 | **主品牌 / 母品牌**（贊助方） |
| 主軸 | 沒受過專業神學訓練的基督徒，討論基督信仰 | 心智/知識內容（評書 + 主題） |
| 主持 | 恩加（主）、亞當（輔），儀芳旁聽 | （待確認，含露臉者） |
| 既有平台 | Podcast、Spotify、Apple、FB、IG | 規劃中：Podcast、FB、IG、YouTube |
| 進度 | 已上架 EP001–EP018 | 籌備中 |

**品牌關係**：恩普拉氏是母品牌，院外門徒路是其下的節目之一。因此院外門徒路的口播前置台詞固定使用「本集節目由恩普拉氏贊助播出」，既佔住未來真正業配的版位，又替主品牌導流。

### 內容模型（恩普拉氏 ↔ YouTube）

- **評論書（評書）**：只上 Podcast。
- **主題影片（露臉）**：Podcast + YouTube 都上。
- 規則：**Podcast 是全集（superset），YouTube 是子集**。凡 YouTube 有的，Podcast 一定有；反之不然。

```
            ┌─────────────────────────────┐
 Podcast →  │  評書（純音訊）   主題（音訊）  │  ← 全部
            └─────────────────────────────┘
                                  │
 YouTube →             ┌──────────┘
                       │  主題（露臉影片）  │  ← 子集
                       └──────────────────┘
```

**決策（2026-05-29）**：書評維持 **Podcast only**，不做靜態影片上 YouTube——以保護 YouTube 主頻道的留存訊號與調性。

**跨平台導流（補救「只看 YouTube」的觀眾）**：

- YouTube 主題影片的**資訊欄 / 結束畫面 / 置頂留言**固定放一句：「完整書評在《恩普拉氏》Podcast 收聽 👉〔連結〕」。
- 反向：Podcast 的主題集口播中提一句「影片版在 YouTube」。
- 雙向漏斗即可把 YouTube-only 的潛在聽眾導去 Podcast，不必把低留存內容硬塞上 YouTube。

## 2. 固定模板台詞（錄一次、重複使用）

每集由三段固定模板 + 當集內容組成。模板先錄好母帶，之後每集剪輯時直接拼接，確保一致性與規模化。

院外門徒路的單集結構（沿用既有企劃）：
口播廣告 → 開場白 → 內容簡介 → 節目內容 → Recap → 結尾。

### 2.1 口播 / 前置台詞（< 2 分鐘，固定版位）

**院外門徒路**（短版，約 10–15 秒）：

> 「本集節目，由恩普拉氏贊助播出。」

> 「本集節目由恩普拉氏贊助播出——恩普拉氏，陪你把想法蓋成一座房子。」
> （加一句品牌標語版，待確認標語）

**恩普拉氏**（自家節目，版位先留空給未來業配）：

> 「本集節目由〔贊助商〕為您帶來。」
> 尚無業配時用：「歡迎收聽恩普拉氏。」

> [!TIP]
> 業配置入原則：口播 < 2 分鐘，固定放在開場白之前，方便日後動態替換（SoundOn 也支援動態插入廣告，但固定口播仍建議自錄一版）。

### 2.2 開場白 / 自我介紹（15–30 秒，最多不超過 60 秒）

好的開場至少要有「節目名稱 + 主持人名稱」，再帶到節目主題與目標聽眾（北極星）。

**院外門徒路**：

> 「歡迎來到《院外門徒路》。我是恩加，我是亞當。我們是兩個沒受過專業神學訓練的基督徒，在這裡跟你一起，把信仰裡那些重要又難講清楚的事，好好聊一遍。」

**恩普拉氏**（待主持人定名後填入）：

> 「歡迎收聽《恩普拉氏》，我是〔主持人〕。在這裡，我們讀書、聊想法，把好書與好觀念，拆給你聽。」
> （主持人名稱、北極星一句話待確認）

### 2.3 結尾（固定）

包含三件事：Recap 收束 → 行動呼籲（CTA） → 道別。

**院外門徒路**：

> 「以上就是今天的內容。如果這集對你有幫助，歡迎在 Facebook、Instagram 搜尋『院外門徒路』追蹤我們，也別忘了把節目推薦給你身邊的人。我們下次見。」

**恩普拉氏**：

> 「今天就聊到這裡。喜歡的話，記得在各大 Podcast 平台訂閱《恩普拉氏》，主題影片可以到 YouTube 看完整版，FB、IG 搜尋『恩普拉氏』也找得到我們。我們下集見。」

## 3. 託管與發佈流程（SoundOn + Spotify + Apple）

### 3.1 結論：一個 SoundOn 帳號可經營兩個節目

- SoundOn **一個 email 帳號可建立多個節目**（與 Firstory 的「一帳號一節目」不同）。
- 限制：**無法多個 email 共管同一個節目**；團隊共管請用一個共用帳號。
- 每個節目各有**獨立的 RSS feed**，各自上架到收聽平台。

### 3.2 收聽平台帳號對應

| 平台 | 帳號需求 | 院外門徒路 | 恩普拉氏 |
|------|---------|-----------|---------|
| SoundOn（託管） | 1 個帳號可放 2 節目 | 已有節目 | 在同帳號「建立 Podcast」新增 |
| Apple Podcast | Apple ID（可專為 Podcast 開一個） | 已串接 | 用同/新 Apple ID 在 Podcasts Connect 提交新 RSS |
| Spotify | Spotify for Creators 帳號 | 已串接 | 同帳號可再 claim 第二個節目的 RSS |
| YouTube | Google 帳號 / 頻道 | （不使用） | 需開頻道（僅放主題影片） |
| FB / IG | 粉專 + IG 商業帳號 | 已有 | 需新建恩普拉氏粉專/IG |

### 3.3 恩普拉氏上架流程（逐步）

1. 用既有 SoundOn 帳號登入 → 後台點「建立 Podcast」。
2. 填頻道資料：**封面圖、節目名稱、作者名稱、節目簡介**（並設定「好記短網址」，注意短網址一旦存檔即不可重用）。
3. 上傳**至少一集**節目（先發一集，後續才能提交 RSS）。
4. 到 [Apple Podcasts Connect](https://podcastsconnect.apple.com) 提交該節目 RSS → 等審核 → 核准後把 Apple 網址貼回 SoundOn 的「平台發布」分頁。
5. 到 Spotify for Creators 提交同一條 RSS（同帳號可管理第二個節目）。
6. 完成後，**之後在 SoundOn 上傳新單集會自動同步到各平台**，不需再次提交。

> [!NOTE]
> 院外門徒路已有 Spotify / Apple，**不需重做**；若想搬進同一個 SoundOn 帳號統一管理，可走「節目搬家」並重新指向 RSS（保留原 Apple/Spotify 上的訂閱）。此步驟非必要，待確認是否要整併。

## 4. 單集命名與編號規劃

### 4.1 院外門徒路（沿用既有格式）

- 檔名 / 內部編號：`院路-EPNNN-題目(部數)`
  - 例：`院路-EP001-出走的先知(1/2)`、`院路-EP015-系統神學 緒論-導論(1/4)`
- 連載多集用 `(1/2)(2/2)` 標示。
- 單集類別（不一定進標題，但企劃內標記）：研經 / 靈修 / 名著 / 佳作 / 小品 / 時事。
- **社群對應：每一單集 1:1 對應一則 FB 貼文 + 一則 IG 貼文。**

### 4.2 恩普拉氏（新設計）

採**單一主編號制**：Podcast EP 號是唯一的 master ID，YouTube 不另編號，只用同號 + 播放清單分類。

- Podcast 內部編號：`恩普-EPNNN`，跨類型連續編號。
- 類型標籤（放在標題或企劃）：
  - `【評書】` = 評論書，**Podcast only**
  - `【主題】` = 主題影片，**Podcast + YouTube**
- 範例：
  - `恩普-EP001【評書】原子習慣：為什麼你戒不掉壞習慣？`（純 Podcast）
  - `恩普-EP002【主題】我用三個方法，半年讀完 50 本書`（Podcast + YouTube）
- **YouTube**：只放 `【主題】` 集數，影片標題用同一 EP 號，靠播放清單（評書音訊版 / 主題影片）分流即可，**毋須第二套編號**。

### 4.3 社群對應總表

|----------|:-------:|:-------:|:--:|:--:|
| 院外門徒路 每集 | ✅ | — | ✅(每集) | ✅(每集) |
| 恩普拉氏【評書】 | ✅ | — | ✅(導流) | ✅(導流) |
| 恩普拉氏【主題】 | ✅ | ✅ | ✅(導流) | ✅(導流) |

> [!IMPORTANT]
> 命名原則（取自製作指南）：標題一眼看懂在講什麼、突顯對聽眾的價值（如何/數字）、放進 SEO 關鍵字、有來賓就寫頭銜。避免「關於 XX 的那些事」這類籠統標題。
